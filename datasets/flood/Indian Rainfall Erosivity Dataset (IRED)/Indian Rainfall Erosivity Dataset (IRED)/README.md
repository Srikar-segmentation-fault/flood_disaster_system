IRED (Indian Rainfall Erosivity Dataset): The data repository for Rainfall Erosivity Data for India. 

This dataset consists of raster layers of Rainfall Erosivity (R-factor), and Erosivity Indices (Fournier Index and Modified Fournier Index) in netcdf format. 
The spatial resolution of netcdf files is 0.12 degree. 

'Dataset' folder contains three folders i.e., 'netcdf', 'tif' and 'Excel'.

'Netcdf' folder having following files:
R-Factor_India.nc - Long term yearly average R-factor (MJ-mm/Ha/h/yr) map for India in netcdf format
MFI_India.nc - Long term yearly average MFI map for India in netcdf format
FI_India.nc - Long term yearly average FI map for India in netcdf format

Likewise 'Tif' folder contains the above three files in .tif format.

'Excel' folder having following file/s:
'R-Factor Distribution.xls' - Distribution of average R-factor (MJ-mm/ha/h/yr) values corresponding to IMD Sub-Divisions, States, and Districts of India in excel sheets.


‘Maps’ folder consists of maps in png format, and ‘Shapefiles’ folder is containing the shapefiles for the districts, states, and IMD Sub-divisions of India.
